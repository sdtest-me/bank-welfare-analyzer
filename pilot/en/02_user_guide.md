# BWA Pilot User Guide

## 1) Load a bank preset
1. Open BWA and go to the bank selection panel.
2. Choose a participating bank preset from the available list.
3. Confirm preset metadata (bank name, data period, source snapshot date).
4. Run analysis.

Expected output panels:
- Welfare Score (0–100)
- Mismatch Score and risk level
- Spiral Gap Analysis
- Impact Index
- Data provenance badges
- Bank Ranking view

## 2) Interpret the Welfare Score (0–100)

The Welfare Score summarizes deterministic alignment between bank behavior indicators and welfare-oriented stage balance criteria.

- **80–100:** Strong alignment profile. Typically indicates lower structural mismatch and stronger stage coherence.
- **60–79:** Moderate alignment. Indicates mixed strengths and targeted improvement opportunities.
- **40–59:** Weak alignment. Suggests material stage imbalance and higher priority for corrective action.
- **0–39:** Critical alignment gap. Requires immediate strategic and risk-governance attention.

Important: score bands are analytical conventions for pilot communication, not regulatory categories.

## 3) Read Spiral Gap Analysis

Spiral Gap Analysis compares:
- Current stage distribution inferred from deterministic indicator mapping.
- Target or reference distribution required for healthier welfare alignment.

How to read:
1. Identify stages with positive or negative gap.
2. Check where concentration is excessive relative to target.
3. Review recommendations linked to high-gap stages.
4. Validate source evidence via provenance badges before policy interpretation.

## 4) Interpret Mismatch Score and risk level

The Mismatch Score quantifies misalignment intensity between observed profile and reference welfare configuration.

General interpretation:
- Lower mismatch = lower structural alignment risk.
- Higher mismatch = elevated strategic/regulatory friction risk.

Risk level labels (example pilot convention):
- Low
- Medium
- High
- Critical

Use mismatch trends over time when available; single-period values should be interpreted with contextual judgment.

## 5) Read data provenance badges

Each badge communicates one or more dimensions:
- **Source type:** macro / public bank disclosure / sectoral dataset.
- **Freshness:** current period or lagged period.
- **Completeness:** full / partial / proxy.
- **Traceability:** direct source link or documented derivation path.

Operational rule: where provenance indicates partial or proxy data, treat resulting insights as directional and flag for validation.

## 6) Use Bank Ranking

Bank Ranking provides comparative ordering across pilot participants for selected metrics.

Recommended workflow:
1. Select ranking metric (Welfare Score, Mismatch Score, Impact Index).
2. Confirm consistent period and source coverage.
3. Compare cluster positions, not just absolute rank.
4. Investigate outliers via Spiral Gap and provenance detail.
5. Use ranking for prioritization dialogue, not as standalone verdict.

## 7) Practical caution

BWA outputs support decisions; they do not replace governance, expert review, or regulatory assessment.
