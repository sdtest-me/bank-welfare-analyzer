# BWA Pilot Presentation Script (15–20 minutes)

## Audience
Bank executives, risk managers, and regulatory officers (Kyrgyzstan and CIS).

## Objective
Demonstrate how BWA delivers deterministic, traceable welfare alignment analysis for practical decision support.

## Timing and flow

### 0:00–2:00 — Opening and framing
Talking points:
- Thank participants and define pilot objective.
- State core message: BWA is deterministic and rules-based, not AI prediction.
- Clarify that outputs support professional judgment; they do not replace governance.

### 2:00–4:00 — What BWA is and is NOT
Talking points:
- Explain the model foundation: Spiral Dynamics stage distribution analysis.
- Explain outputs: Welfare Score, Mismatch Score, Spiral Gap Analysis, Impact Index, provenance badges.
- Explicitly state exclusions: no black-box inference, no hidden data enrichment.

### 4:00–7:00 — Live walkthrough: load bank preset
Demo steps:
1. Open bank preset selector.
2. Choose participant bank.
3. Confirm data period and source snapshot.
4. Run deterministic analysis.

Talking points:
- Same input, same output.
- All outputs linked to traceable source evidence.

### 7:00–11:00 — Interpret core outputs
#### Welfare Score (0–100)
- Explain score band meaning and practical implications.

#### Mismatch Score + risk label
- Show how structural mismatch relates to strategic/regulatory friction risk.

#### Spiral Gap Analysis
- Identify overrepresented and underrepresented stage components.
- Link high gaps to recommended action priorities.

#### Impact Index
- Explain as deterministic impact orientation measure tied to observed configuration.

### 11:00–14:00 — Data provenance and trust
Demo steps:
1. Open provenance badges.
2. Inspect source type and freshness.
3. Show how partial/proxy flags affect confidence.

Talking points:
- Traceability is a decision-quality control layer.
- If provenance is partial, insight is directional and should be validated.

### 14:00–17:00 — Bank Ranking and comparative use
Demo steps:
1. Open ranking panel.
2. Compare by Welfare Score and Mismatch Score.
3. Drill into one outlier using Spiral Gap details.

Talking points:
- Ranking is for prioritization and peer context.
- Avoid overinterpreting single-rank differences without provenance and period checks.

### 17:00–19:00 — Limitations and governance
Talking points:
- Deterministic analysis does not prove causality.
- Output quality depends on public data quality.
- Final decisions remain with institutions and regulators.

### 19:00–20:00 — Close and next steps
Talking points:
- Request structured feedback using pilot template.
- Propose Sponsor Lab path for custom calibration and governance integration.
- Confirm follow-up timeline.

## Presenter checklist
- Keep terminology consistent with glossary.
- Repeat “not an AI prediction system” at least twice.
- Always show provenance before drawing strategic conclusions.
