# Руководство пользователя BWA (пилот)

## 1) Загрузка preset банка
1. Откройте BWA и перейдите к панели выбора банка.
2. Выберите preset банка-участника.
3. Проверьте метаданные (название банка, период данных, дата среза источников).
4. Запустите анализ.

Ожидаемые панели:
- Welfare Score (0–100)
- Mismatch Score и уровень риска
- Spiral Gap Analysis
- Impact Index
- Data provenance badges
- Bank Ranking

## 2) Интерпретация Welfare Score (0–100)

Welfare Score — сводный детерминированный показатель соответствия профиля банка welfare-ориентированным критериям баланса стадий.

- **80–100:** сильное соответствие.
- **60–79:** умеренное соответствие.
- **40–59:** слабое соответствие.
- **0–39:** критический разрыв соответствия.

Важно: диапазоны используются как коммуникационная конвенция пилота, а не регуляторная классификация.

## 3) Чтение Spiral Gap Analysis

Spiral Gap Analysis сопоставляет:
- Текущее распределение стадий (по детерминированному маппингу индикаторов).
- Целевое/референсное распределение для более устойчивого welfare alignment.

Как читать:
1. Определите стадии с положительным/отрицательным разрывом.
2. Найдите зоны избыточной концентрации относительно цели.
3. Сопоставьте высокие разрывы с рекомендациями.
4. Перед выводами проверьте происхождение данных.

## 4) Интерпретация Mismatch Score и уровня риска

Mismatch Score отражает интенсивность несоответствия между наблюдаемым профилем и референсной конфигурацией.

- Низкий mismatch = ниже структурный риск несоответствия.
- Высокий mismatch = выше риск стратегического/регуляторного трения.

Пилотные метки риска:
- Low
- Medium
- High
- Critical

При наличии временных рядов приоритет у тренда, а не у одиночной точки периода.

## 5) Чтение provenance badges

Badge показывает:
- **Тип источника:** макро / публичное раскрытие банка / отраслевой набор.
- **Актуальность:** текущий или лаговый период.
- **Полнота:** full / partial / proxy.
- **Трассируемость:** прямая ссылка на источник или документированный путь вывода.

Правило: если есть partial/proxy, выводы трактуются как направляющие и требуют верификации.

## 6) Использование Bank Ranking

Bank Ranking дает сравнительный порядок банков по выбранной метрике.

Рекомендуемый порядок:
1. Выберите метрику (Welfare Score, Mismatch Score, Impact Index).
2. Убедитесь в сопоставимости периода и покрытия источников.
3. Анализируйте кластеры, а не только место в ранге.
4. Проверяйте выбросы через Spiral Gap и provenance.
5. Используйте ranking для приоритизации, а не как самостоятельный вердикт.

## 7) Практическое ограничение

BWA поддерживает принятие решений, но не заменяет governance-процедуры, экспертную оценку и регуляторный анализ.
